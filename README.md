# STALCRAFT Legacy

Восстановление локального мультиплеера STALCRAFT на основе общественной офлайн-сборки, обозначенной как **2019**. Цель проекта — довести совместную игру с отдельным сервером до рабочего состояния и передать сообществу воспроизводимые инструменты запуска, разработки и документацию. Сохранившиеся механики постепенно восстанавливаются; для отсутствующей серверной логики потребуются новые реализации.

Сейчас это **играбельный локальный прототип**: выделенный сервер запускается, два отдельных клиента подключаются к нему и играют на копии предоставленной карты. Полноценный бой, NPC, задания и исторические серверные сервисы ещё не восстановлены. Точный год выпуска и происхождение исходного пакета независимо не установлены.

## Что уже работает

- Отдельный сервер Minecraft 1.6.4 / Forge и подключение двух настоящих клиентов по TCP/FML.
- Общие изменения мира, сохранение и загрузка после перезапуска, сохранённые позиции игроков.
- Вход на копию карты `RegionsLocal`, восстановление после смерти, чат в обе стороны.
- Перезарядка и синхронизация магазина/расхода боеприпасов. Попадания и урон по цели пока не проверены.
- Исправленные ошибки загрузки объектов карты и сохранения счётчиков. Проверка сохранила все 400 объектов, 38 целей счётчиков, 91 исходное значение и 10 группировок, включая неизвестные этому серверу поля.

Тесты проводились на одном компьютере через `127.0.0.1:25576`, в peaceful-режиме с отключённым появлением монстров. Подготовлены переносимые клиентский и серверный комплекты; подключение с двух физических компьютеров ещё предстоит проверить. Подробности, неудачные эксперименты и границы проверок — в [отчёте](docs/validation.md) и [машиночитаемых свидетельствах](docs/evidence.json).

## Откуда берётся сервер

Основа — встроенный сервер и игровая логика, сохранившиеся в клиенте. Наш код подключает существующие реализации, восстанавливает недостающие связи и исправляет ошибки при работе нескольких клиентов. Это отдельный совместимый слой поверх исходных бинарников, а не полная пересборка декомпилированной игры.

Полного оригинального сервера STALCRAFT у нас нет. Аккаунты, экономика, переходы между серверами, кланы и другие отсутствующие сервисы потребуют отдельной реализации. Уже найденный обработчик попаданий также нуждается в серверных проверках; ближайший этап описан в [плане восстановления боя](docs/combat-next-stage.md).

[Учёт последствий офлайн-патча](docs/offline-patch-audit.md) отделяет изменения общественного пакета, заглушки отсутствующих методов и наши последующие исправления. Реестр содержит 22 группы находок и приоритеты дальнейшей работы; права команд и OP, проверка боевых действий и инвентаря ещё требуют исправления.

История исследования и восстановления других версий остаётся в [stalcraft-reconstruction](https://github.com/Nerawlox/stalcraft-reconstruction). Этот репозиторий посвящён запускаемому проекту.

## Что лежит в репозитории

```text
src/       Код совместимого слоя, исправления и диагностические hooks
launcher/  Переносимый запускатель с окнами настройки подключения
scripts/   Подготовка копий, компиляция, проверка и запуск
docs/      Идентичность входных файлов, результаты тестов и дальнейшая работа
```

Оригинальные JAR, игровые ресурсы, карта, Java, DLL и компилятор здесь не распространяются. Для запуска нужен отдельно полученный совместимый пакет с хешами из [описания входных файлов](docs/input-identity.md). Чужой код и ресурсы сохраняют принадлежность своим авторам; единой лицензии на всю восстановленную игру проект не заявляет.

## Быстрый запуск уже подготовленной копии

В каталоге лаборатории:

1. Открыть `start-server.cmd` и дождаться строки `Done`.
2. Открыть `start-client.cmd`. Первый игрок — `LocalPlayer`.
3. При необходимости открыть `start-second-client.cmd` для `SecondPlayer` в отдельном профиле.
4. Для остановки ввести `stop` в консоли сервера или открыть `stop-server.cmd`. Сервер сохранит мир перед выходом.

Обычные ярлыки работают без таймера завершения, тестовых выдач оружия и автоматических изменений блоков. Исходный мир не используется напрямую: все изменения происходят в проверенной копии.

## Портативный комплект для двух компьютеров

Подготовленные серверный и клиентский ZIP-комплекты включают собственную Java 8 и запускаются без Python и установленной системной Java. Распакуйте их на постоянные места; клиентский архив можно передать другу напрямую. Эти ZIP содержат игровые файлы и не входят в Git.

На сервере используйте `Verify-Files.cmd`, `Start-Server.cmd`, дождитесь `Done`, затем запустите `Allow-Connection.cmd` от имени администратора и разрешите точный IPv4 адрес клиента. На клиенте сначала запустите `Check-Connection.cmd`, затем `Start-Client.cmd`. Для остановки сервера используйте `Stop-Server.cmd`; правило Windows удаляется через `Remove-Connection.cmd`. Настройка сети и шаги подключения описаны в [руководстве для двух компьютеров](docs/two-pc-setup.md).

Сейчас подтверждён запуск двух клиентов на одном компьютере. Связь между двумя физическими компьютерами и Radmin VPN ещё не проверена; подключение к порту само по себе не подтверждает работу игры по сети.

## Подготовка с нуля

Нужны Windows, Python 3.10+, обычная Java 8 и Eclipse ECJ 3.26.0. Проверенная конфигурация использует Temurin 8u504. ECJ доступен в [Maven Central](https://repo.maven.apache.org/maven2/org/eclipse/jdt/ecj/3.26.0/ecj-3.26.0.jar); скрипт проверяет его SHA-256 перед компиляцией.

В PowerShell из корня репозитория указать реальные пути к входным файлам:

```powershell
$packagePath = 'E:\path\to\unpacked\Stalcraft 2019'
$java8Path = 'E:\path\to\java8\bin\java.exe'
$compilerPath = 'E:\path\to\ecj-3.26.0.jar'
$labPath = Join-Path (Get-Location) '.local\lab'
$overlayPath = Join-Path (Get-Location) '.local\overlay'

python scripts/prepare_2019_server_lab.py --source $packagePath --output $labPath
python scripts/build_2019_overlay.py --java $java8Path --ecj $compilerPath --lab $labPath --output $overlayPath
python scripts/prepare_2019_test_clients.py --lab $labPath
python scripts/prepare_2019_world.py --lab $labPath --activate
python scripts/write_2019_launchers.py --java $java8Path --lab $labPath --overlay $overlayPath
```

Каждую команду запускать после успешного завершения предыдущей. Скрипты отказываются перезаписывать существующие лаборатории, результаты компиляции и копии мира: для повторного эксперимента нужен новый каталог. Полный мир и ресурсы занимают несколько гигабайт; подготовка проверяет размеры и хеши.

Папка `.local/` исключена из Git. Исходный пакет не менять и не запускать его лаунчеры против оригинальной карты. Развёрнутые технические инструкции — в [руководстве разработчика](docs/development.md).
