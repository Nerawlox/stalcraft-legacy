# Manual test stage — 5 October 2026

The v3 Windows client/server kits with overlay v36 are ready for a manual test
on two physical PCs. The test will check connection, shared player/world state,
inventory, combat and persistence through normal gameplay.

The users are preparing the session. Results and logs have not yet been reported.
Earlier checks ran on one physical PC and do not confirm a working remote session.
This update changes documentation only.

## Next step

Collect the server log and both client logs, correlate observed bugs, prioritize
blockers and data-loss issues, then reproduce and fix confirmed causes. Retest
the affected behavior before providing updated client/server kits.

Full combat, remote weapon visuals, NPC interactions and historical backend
services remain incomplete. See [validation](validation.md) and
[the v36 stage](test-stage-2026-10-04.md) for existing evidence and limitations.

Detailed local instructions, raw logs, kits and worlds are not part of this report.
